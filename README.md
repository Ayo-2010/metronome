# Tempo/01 — Studio Metronome

A precise Web Audio metronome with tap tempo, time signatures and a warm amber console look.

## Features

- Tempo from 40 to 240 BPM with slider, minus and plus controls
- Tap tempo that averages your recent taps
- Time signatures 2/4, 3/4, 4/4 and 6/8 with an accented first beat
- Beat dots that flash in time, accent included
- Lookahead scheduler for steady audio timing
- Volume control, live bar counter and Space key start/stop
- Settings remembered in localStorage
- Responsive studio-gear layout

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
